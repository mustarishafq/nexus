# Game audio

SFX and lobby music are synthesized in the browser via Web Audio API
(`frontend/src/lib/gameAudio.js`). Optional override files can be placed here:

- `lobby-loop.mp3`
- `question-start.mp3`
- `timer-tick.mp3`
- `answer-lock.mp3`
- `correct.mp3`
- `wrong.mp3`
- `streak.mp3`
- `power-up.mp3`
- `leaderboard.mp3`
- `winner.mp3`
